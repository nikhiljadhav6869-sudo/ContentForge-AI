Explore these features in the repository or local application. This static page explains the project without connecting to a server.

01 / ORCHESTRATION

Follow the agent team

A LangGraph workflow coordinates ten roles. The application visualizes real execution events, agent inputs and outputs, revisions, and human review.

02 / EVIDENCE

Inspect the claims

Trace claims to stored passages, inspect evidence assessments, and review warnings. Evidence matching is a transparent heuristic, not independent fact certification.

03 / EDITORIAL CONTROL

Approve what gets exported

Edit versioned drafts with formatting, review each version’s evidence, and export approved content as Markdown, JSON, or a ZIP package.

Ten specialist roles

Open a role to see its responsibility.

These descriptions explain the implementation. Opening a card does not start an agent or make an AI request.

01 · Supervisor

Turns the brief and constraints into a bounded execution plan. The graph owns routing; model outputs cannot invoke arbitrary tools.

02 · Research

Reads stored source passages and identifies relevant findings, source references, and gaps. Autonomous web search is outside the current implementation.

03 · Strategy

Shapes the campaign’s angle, outline, audience, and tone from the brief and its constraints.

04 · Writer

Creates the requested platform drafts using the strategy and available evidence, and responds to revision feedback.

05 · Fact Checker

Extracts claims and conservatively matches them to passages. Missing or conflicting evidence stays visible for review.

06 · Editor

Refines complete drafts and records editorial notes while preserving version history.

07 · Brand Guardian

Checks drafts against the brand profile and adjusts their voice and presentation.

08 · SEO & Channels

Adapts drafts and metadata for the selected content platforms. It does not publish to social networks.

09 · Quality

Uses an explainable rubric and bounded revision routing. A high score does not remove factual warnings.

10 · Export

Packages the exact versions approved by a person, with evidence references and checksums. Calendar entries are reminders, not automatic publication.

Try the working software

Run the no-key demo on your computer.

Install Git and Docker with Linux containers, then use these commands. Open http://localhost:7860 and choose Explore the live demo.

The demo runs real orchestration with labeled sample outputs. Live AI and email are disabled. This temporary container loses its saved data when removed—download your work first.
